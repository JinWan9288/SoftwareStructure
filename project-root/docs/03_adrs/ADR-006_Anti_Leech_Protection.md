### ADR-006：付费课程资源采用“时间戳防盗链与短期动态 Token 鉴权”机制

---

> **状态:** Accepted
> **日期:** 2026-06-03
> **关联场景:**  QAS-005 (核心点播资源防盗刷) 
> **关联模块:** 鉴权网关, 媒体服务
>
> ---

#### 1. 背景 (Context)
平台核心商业模式依赖高价值付费课程的购买、点播回看与直播进入（QAS-004）。如果系统对音视频资源的拉流 URL（如点播的 `.mp4`/`.m3u8` 地址或直播的 `.flv` 地址）采用静态、固定的文件路径暴露，恶意用户或盗版爬虫只需通过简单的浏览器 F12 抓包，即可将视频源地址长久截获，并分享到外部网站进行非法盗播和刷课。这将严重破坏公司的核心资产和知识产权，需要通过低性能损耗、高安全性的鉴权手段解决。

#### 2. 决策驱动因素(Factors)
在媒体资源的获取路径上，实施基于对称密钥的客户端动态 Token 签名与时间戳防盗链鉴权机制：
* **QAS-005**: 付费资源防盗刷阻止非付费用户通过截获、复制视频 URL 链接进行非法免密看播与白嫖刷课。 
* **约束**: 鉴权机制必须在网络边缘以 O(1) 级的效率极速完成，坚决避免每次流媒体切片握手都回源打垮核心鉴权服务器。

#### 3. 备选方案 (Alternatives)
* **方案A：标准 HTTP Session / JWT 集中回源鉴权**
    * **描述**: 客户端每次向流媒体服务器请求音视频切片时，流媒体集群必须通过同步远程 RPC 调回主站中心网关，验证用户的登录 Session 或解密 JWT。
    * **优点**: 具备最强时效控制力，主站一旦封禁用户或退款，边缘拉流可瞬间切断。 
    * **缺点**: 流媒体播放伴随高频的切片握手，万人并发下每秒会产生数十万次鉴权回源请求，中心网关会在开播一瞬间因连接池耗尽彻底瘫痪。
    * **对质量属性的影响**: 保障了极高的时效安全性，但对系统核心链路的性能与可用性具有毁灭性打击。
* **方案B：共享密钥的时间戳加盐防盗链签名与短期动态播放令牌机制**
    * **描述**: 用户点击看播时，主站预检权益通过，随后利用与 CDN 共享的对称私钥，将 `User_ID`、`Client_IP` 和过期时间戳计算为高强度 MD5 签名参数（`auth_key`）拼入拉流 URL。CDN 边缘节点接收请求时原地执行内存级哈希验签，通过则直接吐流。
    * **优点**: 校验是纯内存、O(1) 复杂度的计算，无需回源查库，完美契合万人高并发拉流的吞吐量要求；绑定 IP 和 5 分钟短 TTL 防范了 URL 的二次转发与重放攻击。
    * **缺点**: 存在时钟漂移风险，且主站无法做到对已发令牌的“秒级强制拉黑断流”（必须等 5 分钟令牌到期）。
    * **对质量属性的影响**: 实现了极致的边缘性能（吞吐量）与极高的防盗播安全性，但在即时控制力上做出了适度权衡。

#### 4. 决策结果 (Result)

综上，**目前采用方案B对当前环境更有利。**
流媒体传输的流量特征决定了鉴权绝对不能频繁回源。方案 B 虽然让平台丧失了“秒级强制踢人下线”的能力（存在最大 5 分钟的滞后窗口），但它完美对冲了防盗链带来的性能损耗，在保证版权资产安全的前提下保护了源站的安全。

#### 5. 后果 (Consequences)
* **正面影响**：成功拦截了 99% 的静态链接盗播和恶意网络爬虫盗刷，CDN 边缘节点鉴权开销极低，完全不影响核心主链路的 QPS 表现。
* **负面影响/权衡**：平台丧失了对正在看播的越权账号实施“即时掐断”的主动权，在恶意用户退款后，其生成的旧 Token 依然可以继续观看最多 5 分钟。
* **引入的技术债务**：平台源站服务器与第三方 CDN 边缘节点必须强制保持严格的时钟 NTP 同步，若出现超过 5 分钟的系统时钟漂移，将导致全网合法用户大面积遭遇 403 误报，必须上线专门的时钟漂移监控告警。

#### 6. 验证计划 (Validation)
* **防盗链篡改与重放测试**：
  1. 模拟合法用户 A（IP: 192.168.1.5）正常购买课程，获取带有 `auth_key` 的拉流 URL，验证其可以顺畅播放。
  2. 复制该拉流 URL，立即在另一台不同网络的测试机 B（IP: 10.0.5.12）上尝试使用播放器拉流。
  3. 保持测试机 A 的环境不变，等待 6 分钟后（使其超过 5 分钟 TTL），再次使用原 URL 建立连接。
* **预期结果**：验证后两种异常测试场景下，CDN 模拟节点是否均能够 100% 拒绝流传输，并向客户端精确返回 `HTTP 403 Forbidden`，证明签名防盗链彻底生效。详细验证过程见：[链接到 docs/05_evidence/PoC_Report.md（由于条件限制仅有验证计划暂未实际验证）](../05_evidence/)
