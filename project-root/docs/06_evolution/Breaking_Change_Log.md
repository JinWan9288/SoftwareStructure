# Breaking_Change_Log

本文档记录系统架构演进过程中，对客户端或其他微服务产生的**破坏性 API 变更 **。

## [v1.0] 支付回调模型从同步切换为异步 (对应 ADR-001a)
- **变更日期**: 2026-06-28
- **影响范围**: 前端订单状态轮询逻辑、所有接入订单的上下游系统。
- **变更描述**: 
  原 `POST /orders` 接口在同步架构下，支付成功后即代表权益发放完毕。变更为异步架构后，支付网关回调成功仅代表资金入账，权益发放存在秒级延迟。
- **适配指南**: 
  前端在拉起支付并收到成功信号后，不能立刻放行用户去观看视频。必须额外轮询 `GET /entitlements/check` 接口，展示“权益核发中”过渡动画，直至接口返回 `granted: true`。

## [v1.0] 防盗链 PlayToken 签名参数调整 (对应 ADR-006)
- **变更日期**: 2026-06-03
- **影响范围**: 前端播放器 SDK、客户端 URL 拼接逻辑。
- **变更描述**:
  原请求直播流仅需传递简单的 `?token=xxx`。新架构引入强防盗链后，播放 URL 的鉴权参数变更为复杂的 `auth_key`，且强依赖客户端真实 IP。
- **适配指南**:
  禁止前端在本地缓存流媒体拉流 URL。每次拉流前，必须实时向 `Live Access Service` 获取最新的 `signedPlayUrl`。该 URL 生命周期仅有 5 分钟，若播放途中发生网络重连，需重新请求网关获取新 URL。
